# Cachos Brasil Valparaíso

Todos os arquivos ficam na MESMA pasta (sem subpastas). Abra `index.html`.

- `config.js`: WhatsApp, Instagram, endereço/horário/mapa (opcionais), serviços e fotos da galeria.
- Fotos reais: coloque na mesma pasta e troque o nome em `config.js` (ex.: src: "foto1.jpg").
- Hero e "O salão": troque `hero.svg` e `sobre.svg` em `index.html`.
- GitHub Pages: suba tudo na raiz do repositório e ative em Settings > Pages.
